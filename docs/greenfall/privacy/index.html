기기 안에만 저장되는 것

앱의 저장 폴더에 JSON 파일(planet_<행성>.json, travel.json, catalog.json)과 소리 설정이 저장됩니다. 앱을 지우면 함께 지워지며, 개발자도 열람할 수 없습니다.

광고 (Google AdMob)

앱을 켤 때 앱 열림(App Open) 광고가 한 번 표시될 수 있습니다. 광고 표시를 위해 Google Mobile Ads SDK(Google LLC)가 다음을 처리합니다.

  • 맞춤 광고 여부는 기기 설정을 따릅니다. (Android: 설정 → Google → 광고 → 광고 ID 재설정/삭제, iOS: 설정 → 개인정보 보호 → 추적)
  • iOS에서 추적 허용을 묻지 않는 경우(ATT 미사용) 추적 목적의 데이터는 쓰지 않습니다.
